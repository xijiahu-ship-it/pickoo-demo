1优先级：时令 > 通用 > 大类
  • 首页从左到右：时令专题 + 通用品类 3 张 + 大类场景 2 张
  • 时令只出当前日期在周期内的，每个 1 张（今天：）；按现有周期同时最多 2 个
2同类内部排序：省得多的在前，没看过的优先
  • 节省金额从大到小：原价 = 每个 CSPU 各站最高价之和，现价 = 各站最低价之和
  • 每个一级分类最多 1 张，避免 3 张通用卡都是家居厨房
  • 没展示过的优先：同一分类下 3 张卡轮换曝光，看过的往后排
3有行为后：个人相关性 + 节省金额 + 时令
  • 切换条件：出现 chat 透露、喜欢 / 收藏 / 盯价、点清单卡或单品任一信号
  • score = 0.40 × 个人相关性 + 0.35 × 节省金额分 + 0.25 × 时令分
  • 个人相关性（按 topic，取最高）：chat 透露场景 / 品类 0.6 > 喜欢 / 收藏 / 盯价所在类目 0.5 > 点过的清单卡 0.4 > 点过的单品所在类目 0.3
  • 节省金额分：同类 topic 内四档；时令分：周期内 = 1
  • 坑位：不再 1 + 3 + 2 硬配额，按 score 取前 6 张；周期内时令至少 1 张，同一 topic 最多 1 张
  • 轮换与过滤：看过没点的卡降权，同 topic 三张轮换；有孩子 / 宠物才出对应清单

Best Price 的承接：不用输入就能看好价。推荐以 CSPU 为粒度。Filter 本期只有两个：场景（可多选）和 Discount %（替换原 Price / Sold，hover 有解释）。卡片 = 图 + 名称 + ✦ 推荐理由（可核对的省钱点 + 使用场景）+ 现价/划线价 + 来源站。

1准入池：质量底线 + 站点配额，不要求降价
  • 质量底线：信息完整度 ≥ 4 / 6 项（标题、描述、规格、属性、卖点、图 ≥ 3）；评论 ≥ 5 条且评分 ≥ 4.0；类目黑名单剔除
  • 站点配额：单一零售商 ≤ 20%
  • 场景切片：按 16 个场景的叶子类目切，每场景 ≥ 5,000 才生效
  • T-1 日更；降价和热门不做准入条件，放到排序里加分
2排序：降幅 + 热度，非冷启动再加个人相关性
  • 冷启动 score = 0.55 × 降幅 + 0.45 × 热度
  • 非冷启动 score = 0.35 × 降幅 + 0.25 × 热度 + 0.40 × 个人相关性（系数为 v1 起始值）
  • 降幅分：30 天降幅四档 0 / 0.3 / 0.6 / 0.9；7 天内新降 +0.1；超上限或无历史价记 0
  • 热度分：评论数叶子内四档（最高 0.6）+ 评论增量前 30%（+0.15）+ Amazon 榜单（+0.15）+ 当季时令类目（+0.1，仅 default）
  • 个人相关性：chat 透露 0.6 > 喜欢 / 收藏 / 盯价 0.5 > 点商品 0.3 > 推荐 query chip 0.1，累加上限 1
  • 选场景 chip 只做过滤，不算信号；切 Discount ↓ 只按降幅
3打散与轮换
  • 叶子类目：每屏 ≤ 4，不连续超过 2
  • 站点：同一零售商每屏 ≤ 1/3
  • 价格带：低 / 中 / 高每屏各 ≥ 1/4
  • 曝光轮换：未点击下次降权 × 0.5，连续 3 次移出当日池
  • 去重：同款多规格、多站按 CSPU 合并，展示最低价站

2场景标签有哪些、如何选 供给 sheet「Okiee 圈品 · 1109 collection_config」

。灰色 = 一期不上 / 待新增。

1标签如何选：先分级，一期只上「强 + 中」
按北美市场规模（NRF / APPA / Circana 等）和竞品是否设频道（Target、DealNews、Slickdeals）打分。强 = 有权威规模数据或 ≥2 家竞品有频道；中 = 两者只占一项；弱 = 都缺。召回池还要 > 3 万 CSPU。
2每个标签如何圈品，作为召回池
标签 = GPC 叶子类目（多数取 Top10）+ 规则，三种：只用类目（12 个）、类目 + 细分词（运动袜 athletic）、类目 + 标题场景词 ± 排除词（圣诞词、排除其他节日）。圈出的即召回池（表中 CSPU），< 5,000 不生效；不要求降价，降幅和热度在排序阶段打分。
3排序与上下线：Feed_Rank + 时令周期
chip 按 Feed_Rank 排；时令标签不限 1 个，周期内的都出、排最前，到期下线。sheet 目前只配了圣诞；7 个时令都配上的话同时最多 2 个（感恩节 + 冬季保暖、圣诞 + 冬季保暖、夏季出游 + 返校）。

CSPU = 该标签 leaf_ids 圈出的商品量（供给只读列，US 2026-11-01，未去重）；点行可展开叶子类目。与 PRD 场景枚举的差异：做饭备餐并入居家焕新、亲子育儿改为儿童用品、个人护理 / 彩妆并入美妆洗护、时尚配饰未保留、Seasonal Picks 以时令标签（圣诞）承接。
